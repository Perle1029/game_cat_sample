# 🐭 ねこよけ 🐱

ネズミを動かして、上から落ちてくる猫をよけるブラウザゲームです。
外部ライブラリなしの HTML ファイル1つで動きます。

## 遊び方

1. `index.html` をダウンロードして、ブラウザで開きます。
2. 「スタート」ボタン（または Enter / Space）でゲーム開始。
3. 矢印キーでネズミを動かし、猫に当たらないようによけ続けます。
4. 猫に当たるとゲームオーバー。「リトライ」ボタン（または Enter / Space）で再挑戦できます。

## 操作

| キー | 動作 |
|---|---|
| ← → ↑ ↓ | ネズミを移動 |
| Enter / Space | スタート・リトライ |
| M | 効果音のオン / オフ |

## ルール

- 生き残った時間に応じてスコアが増えます。
- 猫を1匹よけきるごとに +5 点のボーナス。
- 時間が経つほど、猫の落ちる速さと数が増えていきます。
- ハイスコアはブラウザに保存されます。

## 効果音

音声ファイルは使わず、Web Audio API でその場で音を作っています。

- スタート時のファンファーレ
- 猫をよけたときの「ピッ」
- 100 点ごとのチャイム
- ゲームオーバー時のネズミの「チュッ！」と猫の「ニャ〜」
- ハイスコア更新時のお祝いの音

ブラウザの仕組み上、最初にボタンかキーを押すまで音は鳴りません。

## 動作環境

Chrome、Edge、Firefox、Safari などの最近のブラウザで動きます。
矢印キーで操作するので、キーボードのある PC 向けです。
