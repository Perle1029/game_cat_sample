# 🐭 ねこよけ 🐱

ネズミを動かして、上から落ちてくる猫をよけるブラウザゲームです。
外部ライブラリなしの HTML ファイル1つで動きます。

## 遊び方

1. https://perle1029.github.io/game_cat_sample/ を開きます（PC でも iPhone でも遊べます）。
2. 「スタート」ボタンでゲーム開始。
3. ネズミを動かし、猫に当たらないようによけ続けます。
4. 猫に当たるとゲームオーバー。「リトライ」ボタンで再挑戦できます。

`index.html` をダウンロードして、ブラウザで直接開いても遊べます。

## 操作

### iPhone・スマホ

| 操作 | 動作 |
|---|---|
| 画面を指でなぞる | なぞった分だけネズミが動く（指がネズミに重ならないので、どこをなぞっても OK） |
| 右下のボタン | 効果音のオン / オフ |

iPhone のマナーモード（消音スイッチ）がオンだと効果音は鳴りません。
Safari の共有ボタン →「ホーム画面に追加」で、アプリのように全画面で遊べます。

### PC

| キー | 動作 |
|---|---|
| ← → ↑ ↓ | ネズミを移動（マウスでドラッグしても動かせます） |
| Enter / Space | スタート・リトライ |
| M | 効果音のオン / オフ |

## ルール

- 生き残った時間に応じてスコアが増えます。
- 猫を1匹よけきるごとに +5 点のボーナス。
- 時間が経つほど、猫の落ちる速さと数が増えていきます。
- ハイスコアはブラウザに保存されます。

## 効果音

音声ファイルは使わず、Web Audio API でその場で音を作っています。

- スタート時のファンファーレ
- 猫をよけたときの「ピッ」
- 100 点ごとのチャイム
- ゲームオーバー時のネズミの「チュッ！」と猫の「ニャ〜」
- ハイスコア更新時のお祝いの音

ブラウザの仕組み上、最初にボタンかキーを押すまで音は鳴りません。

## 動作環境

Chrome、Edge、Firefox、Safari などの最近のブラウザで動きます。
画面の大きさに合わせてゲーム画面が自動で縮小されるので、iPhone などのスマホでも遊べます（縦向き推奨）。
